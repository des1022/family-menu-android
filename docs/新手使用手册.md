# 🍚 家庭菜单 · 新手使用手册

> 一句话：这是一款**只存手机里、不联网**的家庭点菜记账 App。

## 一、打开后先认识三块地方

屏幕最下面有 3 个按钮，就是这 App 的三个房间：

| 按钮 | 这个房间是干嘛的 |
| --- | --- |
| 🍽 **今天吃什么**（首页） | **点菜的地方**。所有"上架中"的菜都在这，按分类挑、可以搜索、按标签筛 |
| 📅 **菜单日历** | **记日子**。每天确认过点单后，这里会留下记录；想看以前哪天吃了什么、想照着重做，都来这 |
| 👤 **我的** | **管家房**。录新菜、管理菜、管理分类、看统计、改昵称和深色模式，都在这里 |

> 中间偶尔出现的**右下角悬浮球**写着"今日点单 · N"，是已选菜的实时计数，点它直接去结账清单。

## 二、第一步：把家里的菜录进去

1. 点最下面的 **「我的」**
2. 点 **「上传菜品」**
3. 依次填：
   - **拍照 或 从相册选一张菜的图片**（会自动裁剪成方图）
   - 菜名（比如"西红柿炒蛋"）
   - 分类（选"热菜/主食/汤品"，没有合适的可以自己打一个新分类）
   - 价格（可填可不填）
   - **食材清单（可选）**：写下这道菜要用什么，比如 `西红柿, 鸡蛋, 葱`。
     → 以后每天点完菜，可以直接生成一张"今天要买什么菜"的清单，照着去买就行。
   - **标签（可选）**：点一点给菜贴标签，比如"微辣""简单""15分钟""家常"。
     → 以后想找"不辣的菜""快手菜"时，首页点标签就能筛出来。
4. 确认 **"上架"开关是开的**（开了才会出现在首页）
5. 点 **「保存菜品」**

✅ 回到首页，这道菜就出现啦。

> 想改某道菜？在首页点它 → 进详情页 → 右上角"编辑"；或到「我的 → 管理菜品」里改。

## 三、每天怎么用

### ① 点菜
打开首页 → 看到今天的菜 → 每张卡片右下角点 **「＋加入」** 选上（点错就点 **−** 减掉）。
多选几道没关系，选多少、多少份，右下角悬浮球都记着。

### ② 结账确认
点悬浮球进入 **今日点单**：
- 想加备注？点某道菜下面的"加备注"，比如"少放辣""宝宝不吃香菜"
- 份数多了少了，点 **＋/−**
- 确认没问题 → 点 **「确认点单」** → 会问你要 **生成分享海报**（发给家人看）还是 **返回首页**

确认之后，这顿饭就"记档"了：**菜单日历里今天的格子会留下记录**。

> 💡 之后哪怕你点"清空全部"重新选菜，**已经确认过的那顿不会消失**，日历里一直有。

### ③ 看日子、吃回头草
点 **「菜单日历」**：
- 哪天点过菜，日期下会有一个小数字（当天几份菜）
- 点进去能看到那天每道菜的份数和备注
- 觉得那天的搭配好，点 **「一键复用到今日点单」**，菜单直接搬到今天再改改用
- 单独想复吃某一道，点它右边的小 **＋**

### ④ 每天吃完饭想看看
「我的 → **饮食统计**」：本周/本月最爱吃哪几道、哪个分类吃得多，还有一句小建议。

## 四、常见操作速查表

| 我想… | 怎么做 |
| --- | --- |
| 让新菜出现在首页 | 保存时保持"上架"开启；已下架的到「我的 → 管理菜品」里点上架 |
| 改菜名/换图/改价格 | 首页点菜 → 详情页右上 **编辑** |
| 一次给很多菜上架/下架/删除 | 「我的 → 管理菜品」→ **批量管理** → 勾选 → 底部按钮 |
| 删掉一个分类但保留里面的菜 | 分类管理里删除时选"把菜移到其他分类" |
| 把某道菜设为"常吃" | 详情页右上角点 **☆** 变 **⭐**；首页点"常吃 ⭐"Tab 就能一眼找到爱吃的 |
| 找"不辣又快的菜" | 首页分类栏下面那行 **标签**，点选就行（可叠加筛选） |
| 生成买菜清单 | 今日点单清单页点 **🥬 生成食材清单** → **复制清单**，粘贴发出去 |
| 把菜单发到家人群 | 确认点单后选 **生成分享海报**；或日历/清单里选模板：温馨/简约/节日/可爱 |
| 晚上用不刺眼 | 「我的 → 外观」选 **深色模式**（或跟随系统） |
| 换头像昵称 | 「我的」最上面的卡片，点一下就能改昵称 |

## 五、会用到的小词

- **上架 / 下架**：上架 = 在首页能点到；下架 = 先藏着不让人点（菜还在，随时能再上架）。
- **草稿 / 已确认**：没点"确认点单"前都是草稿，清空会清掉；点过确认就"锁"进日历了，清空不清它。
- **常吃**：你 ⭐ 收藏 + 平时点得多的菜，会聚在首页"常吃"分组。
- **食材清单数字**：如"西红柿 ×2"，指今天有 2 份菜用到西红柿，代表大概要买两人份的量。
- **数据在手机本地**：App 不联网、没账号，所有记录都在这台手机里；**删 App 数据会全没**（见 FAQ）。

## 六、常见问题 FAQ

**Q：装上后提示"不允许安装"？**
第一次从浏览器下载安装，Android 会拦一下。安装时允许"此来源的应用/未知来源"即可（不同手机措辞不同，一般会弹出询问）。

**Q：老版本要升级，会不会把我录的菜弄丢？**
不会。包是"覆盖安装"，数据库会自动升级保留老数据。**但如果先卸载再装 = 数据清空**，所以升级请直接覆盖安装。

**Q：为什么首页找不到我刚录的菜？**
多半是保存时"上架"没打开，或保存前没选上图片。去「我的 → 管理菜品」看那道菜是不是"下架"状态，点编辑把上架打开。

**Q：某道菜显示图片位置是空的？**
图选不上时 App 会提示换一张。可以点进编辑重新选图保存即可。

**Q：确认点单后又想整个改掉今天这顿？**
去今日点单里把不要的菜直接删除，或"清空全部"后重选（已确认的仍留在日历，但你可以到日历那天详情里删掉单行再重新确认）。家人用起来简单点，别被"草稿/已确认"绕晕：**你只管每天点菜、确认，其余交给它记**。

**Q：换新手机，数据能搬过去吗？**
目前**不能**（纯本地单机版，无云同步）。换机需要在新手机上重录。多设备/云端是后续可选方向。

**Q：App 是收费的吗？**
免费、无广告、不联网、不需要注册。

## 七、小提示

- 每道菜**填上食材**后，点单的"买菜清单"才真正有用——一次录菜，长期受益。
- 家里"今天吃啥"最容易纠结——试试 **日历 → 一键复用**，把上周好评的那顿搬回来。
- 海报模板：发家庭群用"温馨/节日"，发朋友用"简约"，哄小朋友用"可爱"。
